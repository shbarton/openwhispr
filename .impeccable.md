# Design Context — CalyxVoice

## Product

**CalyxVoice** is a fork of OpenWhispr that lives inside the Calyx ecosystem — a meeting transcription + AI post-processing app that publishes finished transcripts into a markdown knowledge vault (PlatosRaveCave). It's an Electron desktop app built in React 19 + Tailwind v4 with shadcn/ui primitives.

## Target audience

- Knowledge workers and strategy consultants whose job is *thinking* — interviews, framework work, advisory calls.
- Power users of personal-knowledge tools (Obsidian / Logseq / Notion). They expect rich keyboard-first interactions and live in markdown.
- Specifically Sam Barton (Dragonfly Thinking) and that archetype: strong opinions, intolerant of generic SaaS aesthetics, will notice every detail.
- NOT: a mass-market consumer "AI notes" audience. We're not competing with Otter / Granola on price or distribution — we're competing on *feel*.

## Use cases

- Recording meetings (calls, interviews, advisory sessions) with high-quality diarised transcripts.
- Reviewing the transcript after the meeting and asking an AI agent to summarise it, extract action items, surface follow-ups, draft notes.
- Pre-meeting prep: typing agendas / context into the note body *before* recording, then recording over the top.
- Publishing the finished note as a markdown file into the user's vault so it becomes part of their long-term thinking corpus.

## Brand personality / tone

- **Editorial, not utilitarian.** The app should read like a notebook or a magazine column, not a Mac menu-bar utility.
- **Restrained, not loud.** Generous whitespace. Calm typography. Color appears where it earns meaning — recording state, primary CTAs — not as decoration.
- **A thinking tool.** Implies trust, focus, slowness in a good way. Don't over-animate. Don't shout.
- **Quietly opinionated.** Has a point of view about typography, hierarchy, and information density.

## Visual language

- **Palette**: paper + ink. Soft warm off-white (`#FAFAF7`) light mode; rich dark ink (not pure black) dark mode. Primary accent is an OKLCH green at hue 152 (`oklch(0.520 0.080 152)` light / `oklch(0.650 0.100 152)` dark) — earthy, organic, not Slack-green and not neon.
- **Type contract**: serif display (Instrument Serif or similar) for titles, view headers, and editorial moments; sans body (Inter or system humanist) for UI chrome and content. Use the serif sparingly enough that it lands when it appears.
- **Density**: low. Long line-heights. Comfortable measure. Sidebar widths around 320–360px give the body room to breathe.
- **Borders**: hairline (1px, ~10–15% opacity on the ink). No drop shadows for separation — use spacing and border-bottom hairlines.
- **Corners**: 10–14px on containers, 8px on buttons, full-round on circular action buttons. No sharp brutalism, no pillowy 20px+ everywhere.

## What to avoid

- Glassmorphism / blur as decoration.
- Gradients on text or as background fills (except very subtle paper-warmth).
- Card-in-card-in-card stacking — flatten the hierarchy.
- "Mac utility" patterns: chrome-heavy toolbars, segmented controls everywhere, dense icon strips.
- Generic shadcn defaults left untouched — every primitive needs a Calyx pass.
- Bouncy / elastic motion — gentle ease-out only.
- Cyan-on-dark, purple-to-blue gradients, neon accents, glowing borders — the AI-slop fingerprint.

## Constraints

- Tailwind v4, React 19, Radix primitives via shadcn/ui.
- Must look intentional in both light and dark modes (Sam toggles between them).
- Theme tokens live in `src/index.css` as CSS custom properties. Use semantic Tailwind classes (`bg-primary`, `text-foreground`, etc.) wherever possible — don't hardcode hex unless the token system genuinely doesn't cover it.
- Accessibility: real ARIA labels, keyboard reachable, focus rings visible (use `focus-visible`).

## North-star reference

The Calyx Recorder app (`~/Documents/GitHub/calyx-recorder`) and the broader Chiron design system. The pattern is: soft paper surfaces, generous whitespace, a single accent color used sparingly, serif headings, hairline dividers.
